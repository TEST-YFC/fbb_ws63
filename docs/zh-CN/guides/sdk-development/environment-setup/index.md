# 配置 WS63 开发环境

根据所使用的操作系统和实际开发场景，选择对应的配置指南。

- [**Linux**](linux.md)：配置 Linux 命令行开发环境。
- [**Windows**](windows.md)：选择 VS Code 插件或 CLI 配置 Windows 原生开发环境。
- [**Windows（WSL）**](wsl.md)：在 WSL 2 中配置 Linux 构建环境，Windows 侧使用烧录和串口工具。
- [**Windows（开发者驱动器）**](dev-drive.md)：在 Windows 11 上配置 SDK 和工程的存储位置。
