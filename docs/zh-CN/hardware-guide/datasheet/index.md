# SoC Wi-Fi、BLE和SLE Combo芯片

本文档主要介绍 WS63 系列芯片的各项基本功能，为用户提供 WS63 系列芯片的应用配置方法。

WS63 系列是集成 Wi-Fi 6、BLE (Bluetooth Low Energy) 5.4 和 SLE (SparkLink Low Energy) 1.0 的 Combo 芯片，支持丰富的网络协议和安全特性。
