# I2S

<a id="6.8.1"></a>
## 概述

I2S 模块是 APB 总线上的从设备、I2S 总线上的主/从设备。

<a id="6.8.2"></a>
## 功能描述

- 支持 Master/Slave 模式；

- 支持TRX的左右声道各自独立FIFO，FIFO规格为32X8；

- 支持 8kHz/16kHz/32kHz/44.1kHz/48kHz/96kHz/128kHz;

- 支持 16/24/32 位的传输工作模式；

- 支持 I2S 协议/PCM-TDM 协议（PCM-TDM 只支持 RX 方向的 16 位传输工作模式）。
