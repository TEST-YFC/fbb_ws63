# WS63 1.10.108 发布说明

本文记录 WS63 SDK 相对 [1.10.106](WS63-1.10.106.md) 的主要变化，覆盖从 `1.10.106` 标签到当前 `1.10.108` 源码的累计变更。适用于 WS63 系列 Wi-Fi、BLE 和 SLE Combo 芯片；雷达相关内容仅适用于支持该能力的型号。

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，按变更类型归类；版本号沿用 WS63 SDK 的既有编号规则。

## 1.10.108

### Added

- 新增 **无线控制接口**：BLE 提供协议栈使能状态查询 `ble_is_enable()`、广播随机延迟配置 `gap_ble_set_adv_random_delay()`；SLE 提供取消建连 `sle_create_connection_cancel()`、协议栈状态查询 `sle_get_stack_state()` 和 C 帧相关接口。
- 新增 **Mesh 接口与示例**：提供 BLE Mesh、SLE Mesh 公开头文件和相关示例，以及 `ws63-liteos-app-mesh` 构建目标。
- 新增 **Matter 集成**：提供 `ws63-liteos-matter` 构建目标，以及基于 `connectedhomeip` 的 Matter 1.4.2 组件。开发前需获取仓库固定的子模块版本，具体步骤见 [Matter 用户指南](../Matter用户指南/Matter用户指南.md)。
- 新增 **产测调试命令**：增加 `AT+EFUSEREADCALIINFO`，用于读取产测保存的校准参数；该命令仅用于调试读取信息，不影响产测流程。
- 新增 **BLE 示例**：Hello BLE 连接、通知和属性读写，按键 HID，AHT20/BMP280 传感器上报，UART 透传，以及向华为云 IoTDA 上报环境数据的网关。入口见 [BLE 参考案例](../../samples/connectivity/ble/index.md)。
- 新增 **SLE 示例**：Hello SLE 连接与属性通信、连接参数调整、PHY/MCS 切换、RSSI 测距、传感器上报、UART 透传、设备参数持久化和分片传输。入口见 [SLE 参考案例](../../samples/connectivity/sle/index.md)。
- 新增 **OSAL 示例**：覆盖任务并发、动态内存、中断管理、事件、消息队列、互斥锁和信号量，统一通过 OS 示例配置入口选择。
- 新增 **外设入门与保护示例**：Hello World、OLED 显示、[RTC](../../samples/peripherals/rtc/rtc.md) 和 [PMP](../../samples/peripherals/pmp/pmp.md)，配套提供配置与操作说明。
- 新增 **树外工程与组件集成**：支持独立应用工程、外部组件 Kconfig 和 CMake 接入，以及外部板级初始化入口，减少应用与 SDK 目录的耦合。
- 新增 HH-D111、DFRobot Beetle WS63 和 WCL-63X-DK01 等开发板资料，并补充合作厂商案例指南，见[开发板选型](../../get-started/board-introduction.md)。

### Changed

- **雷达公开头文件**：原 `slp_radar_service.h`、`slp_radar_errcode.h` 调整为 `radar_service_slp.h`、`radar_errcode.h`，并增加 `radar_service_sub_6g.h`。使用旧接口的应用需按当前头文件适配。
- **TLS 组件**：默认应用目标从 Mbed TLS `3.1.0` 切换到 `3.6.0`，并使用配套硬件加速组件。升级自定义 TLS 配置或应用时，需要与当前头文件、配置和库保持一致。
- **Wi-Fi 稳定性与兼容性**：默认关闭 802.11n 40 MHz；优化 Wi-Fi 初始化/去初始化流程的资源锁保护，支持并发调用场景；优化 WPA3 与特定路由器的兼容性。
- **BLE、SLE**：增强 BLE/SLE AT 命令参数范围校验；SLE 协议栈初始化时默认支持从 eFuse 读取 MAC 地址，业务侧仍可通过 API 修改；优化 SLE 协议兼容性；新增 `AT+SLECONNCANCEL` 连接取消命令。
- **系统与外设**：修复 UART 初始化/去初始化的概率性错误并提升稳定性；优化系统启动时间和维测信息，增加任务栈信息打印及维测命令；PWM Sample 支持 preload 配置方式；修正 QSPI 时钟配置偏差，使配置值与实际生效值一致。
- **感知能力**：优化 Sample 算法参数，提升检测效果。
- **加密配置**：Mbed TLS 默认加密曲线配置调整为 `config-ws-iot_v3.6.0.h`，具体配置说明见《安全软件开发指南》1.2 章节。
- **构建工具约定**：芯片配置声明 FBB CLI 最低版本 `1.1.0` 和 HCC 工具链版本 `7.3.0-20240618`；新增目标查询、示例查询、工程创建、烧录和串口监视的配套入口。首次开发见[快速入门](../../get-started/index.md)。
- **开发文档**：补充整体架构、API 参考、外设与无线案例、LiteOS 和故障定位资料；快速入门按 CLI、VS Code 两条流程组织，统一 Hello World 的配置、构建、烧录和串口验证步骤。

### Removed

- 移除旧版 SLP 雷达示例及其配置入口；当前雷达示例保留 STA、SoftAP 和无线场景。依赖旧 `slp_sample` 的工程需要重新适配，不能直接沿用旧示例路径和配置。

### Fixed

- 修复 **ADC 未上电错误码**：自动扫描通道使能操作在 ADC 未上电时，返回 `ERRCODE_ADC_NOT_POWER_ON`，不再误用 PWM 错误码；同步修正差分通道参数 `positive_ch` 的拼写。
- 修复 **OLED 画线死循环**：`ssd1306_DrawLine()` 使用实际迭代坐标判断终点，修复 Hello World OLED 及相关开发板示例中的相同问题。
- 修复 **示例构建依赖**：补齐 RTC 头文件与链接依赖，按 I2C 示例所需选择驱动模式，并修正 MQTT、HiLink 示例的构建配置。
- 修复 **Matter NV 删除配置**：为 Matter 目标启用 `CONFIG_NV_SUPPORT_DELETE_KEY`，支持键值删除操作。
- 修复 **构建脚本兼容性**：用 `shutil.which()` 替换已移除的 `distutils.spawn.find_executable()`，避免新版本 Python 因缺少 `distutils` 无法启动构建。

### Security

- 移除 Wi-Fi 配网示例中对 Wi-Fi 密码的明文日志输出，降低串口日志泄露凭据的风险。
